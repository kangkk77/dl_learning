# dl-learning

我的深度学习学习记录：每天的练习代码放在 `dayXX/` 目录下，学习进度和心得记在 [log.md](log.md)。

## 环境

- conda 环境：`dl`（Python 3.11，Miniforge 管理）
- PyTorch（Apple M1，MPS 加速）+ numpy / pandas / matplotlib / jupyter
- 检查环境：`conda activate dl && python check_env.py`

## 目录

```
dl-learning/
├── README.md
├── log.md          # 学习日志
├── check_env.py    # 环境检查脚本
└── day01/          # 每天一个目录
```
